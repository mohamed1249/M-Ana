# M-Ana

M-Ana is a practical Python toolkit for the repeated parts of data-science work:
cleaning and loading data, experimentation, forecasting, retrieval, ranking,
recommendation, and database workflows.

The core installation stays small. Heavier integrations are grouped into
optional extras so a project installs only what it uses.

```bash
pip install M_Ana_package
pip install "M_Ana_package[rag]"
```

Start with the [quick start](quickstart.md), then use the [API reference](api.md)
for the stable public namespaces.

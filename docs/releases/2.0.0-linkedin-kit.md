## One-sentence description

MAna turns the reusable code I kept rebuilding across data-science projects into
one connected Python toolkit for data preparation, analysis, modeling, statistics,
time series, NLP, RAG, recommenders, and database workflows.

## The personal story

MAna began as scattered helper functions and notebook snippets. The goal was not
to create another huge framework; it was to make repeated data-science work easier
to reuse, test, document, and connect. Version 2.0.0 is the point where those pieces
work as a coherent package and the documentation demonstrates MAna using MAna.

## Verified highlights

- A shared `MAna.data` layer now drives dataset loading and structural preprocessing
  throughout the module notebooks.
- `DataCleaner` supports nested list, dictionary, set, and NumPy-array values when
  profiling data quality and identifying duplicate rows, including movie metadata.
- PostgreSQL is a first-class database workflow, including secure environment-based
  URLs, schema-aware batched upserts, `COPY`, DataFrame-to-DDL helpers, index creation,
  table health, slow-query inspection, and query-plan analysis.
- Time-series workflows cover preprocessing, feature engineering, ARIMA-family and
  optional neural forecasting, hybrid/ensemble forecasts, decomposition, anomaly
  detection, evaluation, and visualization.
- Statistics include hypothesis tests, effect sizes, A/B and multivariate testing,
  power/sample-size helpers, Bayesian proportion comparison, and visual diagnostics.
- NLP includes cleaning, chunking, vectorization, sentiment, topic modeling,
  embeddings, semantic search, and leakage-safe mixed-feature classifiers.
- RAG includes deterministic document records, persistent semantic indexes,
  grounded context and citations, provider-neutral orchestration, OpenAI-compatible
  adapters, FAISS/Pinecone helpers, fusion, and retrieval metrics.
- Recommenders use configurable user/item/score fields rather than movie-specific
  assumptions and include popularity, content, item-KNN, hybrid ranking, temporal
  holdouts, and ranking evaluation.
- The optional Spark/`MAna.big` namespace was removed to keep the package focused
  and avoid forcing a fragile ecosystem into the core toolkit.

## Validation evidence

- 96 automated tests pass locally.
- Full package lint checks pass for MAna and its tests.
- Nine connected module notebooks compile and their shared loading/preprocessing
  sections have been executed as release checks.
- Wheel and source distributions are built and checked before publication.
- GitHub Actions tests Python 3.9, 3.10, 3.11, 3.12, and 3.13, plus package quality
  and strict documentation builds.

Do not describe MAna as enterprise-certified, battle-tested at scale, or a drop-in
replacement for specialized production platforms. The accurate positioning is a
personal Beta-stage toolkit with automated validation that other data scientists
can inspect, adapt, and help improve.

## Why version 2.0.0

Removing the public `MAna.big` namespace is an intentional breaking change. The
major-version bump follows semantic versioning and makes the narrower scope explicit.

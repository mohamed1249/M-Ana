# Modeling Module Notebook

This notebook documents `MAna.modeling`, the model-building and model-lifecycle
layer for classification, regression, clustering, evaluation reports,
cross-validation, feature importance, automatic model comparison,
hyperparameter search, model registry/versioning, sklearn persistence,
modeling visualizations, and optional Keras/PyTorch utilities.

It uses real datasets from the documentation set: women's clothing reviews for
classification, Dubai electricity demand for regression, and movie metadata for
clustering.

Open it here:

[MAna.modeling - Evaluation, Auto-Modeling, Registry, and Deep-Learning Helpers](../notebooks/modeling_module.ipynb)

The code comments are intentionally detailed because modeling workflows fail
quietly when data leakage, weak baselines, missing metadata, or undocumented
model versions slip into the process.

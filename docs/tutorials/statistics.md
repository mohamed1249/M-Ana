# Statistics Module Notebook

This notebook documents `MAna.stata`, the statistical testing and experiment
analysis layer of MAna. It uses real datasets from older project work:
Udacity A/B test data, country segments, Google Play app data, and stock-market
prices.

The notebook focuses on statistical workflow, not isolated formulas:
descriptive summaries, assumptions, effect sizes, confidence intervals,
parametric and non-parametric tests, A/B testing, Bayesian proportion
comparison, multiple-testing correction, power planning, and statistical
visualizations.

Open it here:

[MAna.stata - Statistical Testing, Effect Sizes, and Experiments](../notebooks/stata_module.ipynb)

The code comments are intentionally heavier than usual because statistics is
full of small decision points. The notebook explains why a table is prepared a
certain way before calling the test.
